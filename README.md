# Ri'ach · Aromaterapia Artesanal — Demo

Sitio estático demo para [@riachhn](https://www.instagram.com/riachhn/).

- `index.html` — landing + catálogo destacado (filtro por momento)
- `catalogo.html` — catálogo completo: categorías, búsqueda, orden, vista rápida
- Carrito lateral con pedido por WhatsApp (número demo)

Precios y aromas son ilustrativos. Sin build: abrir `index.html` o servir con `python3 -m http.server`.

Para cambiar productos editar `js/products.js`. Para el WhatsApp real, cambiar `WA` en `js/app.js`.
